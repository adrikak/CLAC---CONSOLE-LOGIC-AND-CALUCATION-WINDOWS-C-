# Calculator Search & Execution System (CLAC)

The Calculator Search & Execution System (CLAC) is a comprehensive console-based application developed in C that integrates multiple computational and conversion utilities into a single platform. The project was designed to provide users with a structured, menu-driven environment for performing mathematical calculations, scientific operations, and unit conversions without relying on multiple separate applications.

The system combines several modules including a scientific calculator, temperature converter, currency converter, and unit converter, allowing users to perform a wide range of calculations efficiently. To improve usability, the application features an interactive console interface with animated menus, colored output, conversion history tracking, and organized navigation between modules.

This project demonstrates the practical implementation of core programming concepts such as modular programming, functions, structures, arrays, file handling, enumerations, macros, and input validation. The codebase was developed with a focus on maintainability, readability, and scalability, making it both a functional utility and a valuable academic learning project.

## Key Features

### Scientific Calculator
- Basic arithmetic operations
- Logarithmic calculations

### Temperature Converter
- Celsius ↔ Fahrenheit

### Currency Converter
- INR ↔ USD
- INR ↔ EUR
- INR ↔ GBP
- INR ↔ JPY

### Unit Converter

- Mass Conversion
- Time Conversion
- Speed Conversion
- Energy / Power Conversion

### Additional Features
- Conversion history tracking
- Menu-driven interface
- Animated console banners
- Color-coded output
- Error handling and input validation
